# Рассылка стейтментов и отчётов по дизелю в Telegram

Два скрипта, оба запускаются вручную раз в неделю от вашего личного
Telegram-аккаунта (не бота):

- `send_statements.py` — рассылает PDF-стейтменты водителям
- `send_fuel_reports.py` — рассылает картинку-отчёт по дизелю владельцам-операторам

Оба используют общий `config.py` (логин один на оба скрипта) и общий
`telegram_common.py` — модуль, который ищет группы в папке Telegram и
запоминает, какую группу вы выбрали для каждого водителя вручную.

## Установка (один раз)

1. Установите Python 3.10+ (если ещё нет): https://www.python.org/downloads/
2. Скачайте все файлы в отдельную папку на компьютере (включая
   `telegram_common.py` — без него скрипты не запустятся).
3. Откройте терминал / командную строку в этой папке и выполните:

   ```
   pip install -r requirements.txt
   ```

4. Получите API-ключи Telegram:
   - Зайдите на https://my.telegram.org с телефона, привязанного к вашему аккаунту
   - Log in -> API development tools
   - Заполните любое название приложения и платформу (например "Statements Bot", Desktop)
   - Скопируйте `api_id` и `api_hash`

5. Откройте `config.py` и впишите:
   - `API_ID` и `API_HASH` из шага 4
   - `PHONE` — ваш номер телефона в формате `+1XXXXXXXXXX`
   - `TELEGRAM_FOLDER_NAME` — точное название вашей папки в Telegram со
     всеми группами "Accounting & ..." (сейчас стоит `"RC Accounting"`,
     поменяйте, если у вас называется иначе — важно, чтобы совпадало
     ТОЧНО с тем, что видно в Telegram: Настройки -> Папки чатов)

## Первый запуск (любого из скриптов)

```
python send_statements.py
```

Telegram пришлёт код подтверждения (в само приложение Telegram или SMS) —
введите его в терминал. После этого создастся файл `my_account.session` —
при следующих запусках (в том числе для второго скрипта) повторный вход
не понадобится.

**Файл `my_account.session` — это ключ к вашему аккаунту, никому его не
передавайте и не публикуйте (например, на GitHub).**

## Как скрипты находят нужную группу

Оба скрипта ищут группы в **два прохода**:

1. Сначала — группы из папки Telegram `TELEGRAM_FOLDER_NAME` (основной, приоритетный список).
2. Затем — резервный поиск **по всем вашим чатам**, у которых название
   начинается с `Accounting & ` (см. `GROUP_PREFIX` в `config.py`). Так
   находятся группы, которые ещё не добавлены в саму папку — например
   отдельные OWN-группы вроде `Accounting & DAVID - Aman OWN #6822`.

Оба списка объединяются (без дублей) — и уже по этому общему списку идёт
сопоставление и показывается список для ручного выбора.

**Рекомендация:** если какая-то группа регулярно находится только через
резервный поиск, добавьте её в саму папку `TELEGRAM_FOLDER_NAME` в
Telegram — тогда поиск будет быстрее и предсказуемее. (по имени из файла PDF или из Excel) скрипт по
очереди пробует:

1. **Сохранённое ранее сопоставление** — файл `driver_group_map.json`,
   общий для обоих скриптов. Если водителя туда уже сохраняли (вручную или
   автоматически) — группа берётся сразу, без вопросов.
2. **Автоматическое сопоставление по имени** — сначала точное совпадение,
   потом по набору слов без учёта порядка (например "Alpinar Ercan" в Excel
   находит группу "Accounting & Ercan Alpinar").
3. **Ручной выбор** — если ни то, ни другое не сработало, скрипт прямо в
   терминале покажет пронумерованный список всех групп из папки:
   ```
   Не нашёл группу для: Хасан Демир  (файл: driver_settlement_3501_Hasan_Demir.pdf)
   Доступные группы в папке:
     1. Accounting & Hasan D.
     2. Accounting & Ermek - Akilay OWN #507
     3. Accounting & Enes Kaya
     ...
     0. Пропустить (не отправлять)
   Введите номер группы:
   ```
   Вводите номер — файл уйдёт в эту группу, а выбор запомнится в
   `driver_group_map.json` на будущее. Введёте `0` (или просто Enter) —
   этот файл будет пропущен, отправите его в этот раз вручную сами.

### Если что-то привязалось не туда

Откройте `driver_group_map.json` любым текстовым редактором — это простой
список `"имя водителя": "название группы"`. Удалите строку с ошибочной
привязкой и сохраните файл — при следующем запуске скрипт спросит про
этого водителя заново.

## 1. Стейтменты (send_statements.py)

### Каждую неделю

1. Экспортируйте все стейтменты из DataTruck/EZLogs.
2. Сложите все PDF-файлы в папку `statements` (путь настраивается в
   `config.py` -> `STATEMENTS_FOLDER`).
3. Запустите:
   ```
   python send_statements.py
   ```
4. Введите неделю, когда спросит, например: `June 21 - 27`
5. Скрипт переименует каждый PDF в `Имя Фамилия Неделя.pdf` прямо в папке
   и отправит его под этим именем в найденную группу (см. выше, как он её
   находит). В конце покажет отчёт: кому отправлено, кого не нашёл/пропустили.

### Формат имени файла

Ожидается `driver_settlement_<номер>_Имя_Фамилия.pdf`. Дополнительно
поддерживаются комбинированные OWN-группы: файл вида
`Имя1___Имя2_OWN__1234.pdf` превращается в `Имя1 - Имя2 OWN #1234` при
поиске совпадения по имени (но если имя совсем не похоже на название
группы — как обычно, спросит вручную).

### Повторный запуск

Так как файлы физически переименовываются, повторно запускать скрипт на
той же партии не получится — переименованные файлы больше не подходят под
исходный шаблон и попадут в "не отправлено". Это нормально: значит, они уже
отправлены на прошлом запуске. Перед новой неделей кладите в папку свежий
экспорт.

## 2. Отчёты по дизелю (send_fuel_reports.py)

### Каждую неделю

1. Кладёте недельный Excel-файл (например `Fuel_JULY_26_-_AUG_01.xlsx`) в
   папку `fuel_reports` (путь настраивается в `config.py` -> `FUEL_FOLDER`).
   В папке должен быть ровно один `.xlsx` файл за раз.
2. Запускаете:
   ```
   python send_fuel_reports.py
   ```
3. Скрипт сам:
   - возьмёт период из названия файла (`Fuel_JULY_26_-_AUG_01.xlsx` →
     "JULY 26 - AUG 01")
   - прочитает первый лист, у которого имя не "Summary" (лист Summary
     игнорируется всегда)
   - возьмёт только те строки, где ячейка с именем водителя закрашена
     **жёлтым** (любой другой цвет, включая синий и отсутствие заливки,
     игнорируется без исключений)
   - сгруппирует строки по водителю
   - нарисует табличку (как скриншот: даты, локация, галлоны, цена,
     скидка, итоговая сумма снизу) для каждого водителя
   - найдёт группу тем же способом, что и `send_statements.py` (см. раздел
     выше) и отправит картинку
   - покажет отчёт: кому отправлено, кого пропустили

### Настройка

В начале `send_fuel_reports.py`:
- `YELLOW_HEX` — код цвета заливки, означающий "отправить" (сейчас жёлтый, `FFFF00`)
- `DISPLAY_COLUMNS` — какие колонки Excel показывать в картинке и в каком порядке

## 3. Стейтменты LVS / DataTruck (send_statements_lvs.py)

Отдельный скрипт для второй компании. Работает по тому же принципу, но
учитывает другие форматы имён.

### Каждую неделю

1. Сложите PDF-стейтменты LVS в папку `statements_lvs`
   (путь в `config.py` -> `LVS_STATEMENTS_FOLDER`).
2. Запустите:
   ```
   python send_statements_lvs.py
   ```
3. Введите неделю, например: `Sep 06 - 14`

### Чем отличается от RC-скрипта

**Формат имени файла:** `ST-001644_NECATI_ABI_None.pdf` — номер стейтмента
спереди, имя водителя в середине, в конце Unit Number (`None` или число,
отбрасывается). Имя может быть из **двух ИЛИ трёх слов** —
`FELIX_GABRIEL_OSORIO` разбирается так же корректно, как `NECATI_ABI`.

**Названия групп:** имя стоит впереди, служебные слова сзади, и написаны
они по-разному. Скрипт отбрасывает служебные слова
(`accounting`, `lvs`, `ivs`, `team`, `acc`, `manager`) и сравнивает только
слова имени, поэтому все эти варианты находятся автоматически:

| Файл | Группа |
|---|---|
| `ST-…_NECATI_ABI_None.pdf` | NECATI ABI Accounting LVS |
| `ST-…_Jean_Sony_Joseph_412.pdf` | Jean Sony Joseph ACCOUNTING |
| `ST-…_JARRETT_NICORDO_None.pdf` | JARRETT NICORDO Accounting IVS *(опечатка в группе)* |
| `ST-…_FELIX_GABRIEL_OSORIO_None.pdf` | FELIX GABRIEL OSORIO Accounting LVS |

Если понадобится добавить ещё служебных слов — правьте `GROUP_STOPWORDS`
в начале `send_statements_lvs.py`.

**Отдельная карта привязок:** LVS использует свой файл
`driver_group_map_lvs.json` (не смешивается с RC-привязками в
`driver_group_map.json`).

**Поиск групп:** сначала папка `LVS_FOLDER_NAME` из `config.py`, затем
резервно — все чаты, в названии которых есть слово "Accounting". Если
папки с таким названием у вас нет, скрипт просто возьмёт второй способ,
ничего настраивать не обязательно.

## Важно про использование личного аккаунта

Это не бот, а автоматизация через ваш обычный аккаунт (тот же протокол,
что использует приложение Telegram). Правила Telegram не приветствуют
автоматизацию личных аккаунтов "оптом", но еженедельная отправка
десятка файлов в группы, где вы реальный участник — обычная бытовая
автоматизация, а не спам-паттерн. Не запускайте оба скрипта одновременно
с двух мест и не превращайте это в массовую рассылку незнакомым людям.
